Open source software in Convertopia

Convertopia uses the open source software listed below. Thank you to everyone who works on these projects.

FFmpeg and LAME (LGPL)

The video and audio engine is FFmpeg 7.1.1, licensed under the GNU Lesser General Public License version 2.1 or later. It is built from unmodified FFmpeg source as an LGPL-only build (no GPL or non-free components) and linked dynamically, so the FFmpeg libraries are separate files inside the app (libavcodec.so, libavformat.so, libavfilter.so, libavutil.so, libswscale.so, libswresample.so, libavdevice.so) and can be replaced. The MP3 encoder is LAME 3.100 (GNU LGPL version 2 or later), built into libavcodec.so.

Complete corresponding source code of the exact versions used:

  • ffmpeg-7.1.1.tar.xz (unmodified upstream release)
  • lame-3.100.tar.gz (unmodified upstream release)
  • build-engine.sh, the script and configure options used to build the engine with Android NDK r27c
  • Licence text: LGPL-2.1.txt, LAME-COPYING.txt
